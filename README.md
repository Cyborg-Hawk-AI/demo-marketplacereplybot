## Product specification

**Target customer:** Ecommerce sellers managing 2+ marketplaces (Amazon, eBay, Etsy, Shopify) with international customers

### Core MVP features
- Connect marketplace accounts via API; auto-ingest product catalog, FAQs, and return policies
- AI drafts context-aware replies in customer's detected language, matching store tone
- One-click approve or edit before sending; optional fully-auto mode for routine queries
- Escalation rules: flag negative sentiment or refund requests for human review
- Weekly analytics dashboard showing reply volume, average response time, and escalation rate

**Pricing:** Tiered monthly subscription by reply volume at $49/mo (500 replies), $99/mo (2,000 replies), $249/mo (unlimited)

**Go-to-market:** Reddit r/ecommerce, r/FulfillmentByAmazon, Etsy seller forums, cold outreach to sellers with negative reviews citing slow responses

**Competitive landscape:** Gorgias and Freshdesk exist but are generic helpdesks; no niche tool focused on multilingual marketplace-specific reply drafting with policy context injection

**Agentic automation plan:** AI agent polls new messages every 5 minutes, retrieves relevant product/policy context via RAG, drafts reply, scores confidence — auto-sends if confidence >0.92, else queues for human review; daily digest email generated automatically

**MVP estimate:** Python FastAPI backend + Next.js frontend + self-hosted Mistral/LLaMA for drafting + marketplace OAuth integrations; 3 weeks to launch with Amazon SP-API and Etsy API first
